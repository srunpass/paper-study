# 知页 · Paper Study

一个运行在本机浏览器中的英文论文阅读与学习工具。导入论文后，可以中英对照阅读、让 Codex 讲解选段、查询相关资料，并保存学习笔记。

**本项目不提供 Codex 账号、API Key 或登录凭据。每位使用者需要自行安装 Codex CLI，使用自己的账户登录，并具备可用额度。**

## 功能

- 导入 PDF、TXT、Markdown，或直接粘贴英文文本。
- **版式对照**：原文使用 PDF 原始画布，译文沿原页的标题、段落和栏位排版，保留图示及独立公式；可放大至 200%。
- **双向句子定位**：在原文或译文点击／拖选句子，另一侧自动高亮并定位；底部显示完整句对，支持上一句／下一句。
- **段落精读**：用更大的文字阅读中英段落，译文过长时可从原版区域展开到精读。
- 逐页翻译并自动缓存；全文翻译可以停止并继续。文献库和学习助手均可收起。
- 选段讲解、术语解释、论文概览、连续追问和理解自测。
- 按需开启联网查询，实际搜索后的回答显示「已联网」及来源链接。
- 文献、译文、阅读页码、对话与笔记保存在当前浏览器本地；支持导出 Markdown 学习记录。

## 使用前提

| 项目 | 要求 |
| --- | --- |
| 操作系统 | macOS 已验证；Linux 可使用命令行启动；Windows 请在 WSL2 中运行，原生 Windows 暂不支持 |
| Node.js | **22.13 或更高版本**，建议使用 **24 LTS**；仓库提供 `.nvmrc` |
| npm 与 Git | 需要可用的 npm 和 Git，npm 随 Node.js 安装 |
| Codex CLI | 安装当前官方版本，支持 `exec --ignore-user-config --ephemeral --json` 等参数 |
| Codex 登录 | 在运行服务的同一操作系统用户下执行 `codex login`，并具备可用额度 |
| 浏览器 | 建议使用当前版本的 Chrome、Edge、Firefox 或 Safari；需要允许 IndexedDB 本地存储 |
| 网络 | 安装依赖及调用 Codex 时需要网络；AI 服务可用性和额度由服务提供方决定 |
| 本机端口 | 正常运行使用 `4317`；开发模式额外使用 `4318` |

阅读和保存已导入的本地资料不要求持续调用 AI；翻译、讲解、提问与联网查询需要连接 Codex 服务。

## 快速开始

### 1. 安装并登录 Codex

```bash
# 在安装 Node.js 后执行
npm install -g @openai/codex
codex login
codex login status
```

按照 CLI 提示在浏览器中完成你自己的登录。不要将账号凭据复制进项目，也不要向维护者发送登录文件、密钥或令牌。安装方式和账户资格以 [Codex 官方说明](https://developers.openai.com/codex/cli) 为准。

### 2. 下载并运行知页

```bash
git clone https://github.com/srunpass/paper-study.git
cd paper-study

# 如已安装 nvm，可先运行 nvm install && nvm use
npm ci
npm run doctor
npm run build
npm start
```

在浏览器打开 **[http://127.0.0.1:4317](http://127.0.0.1:4317)**。

`npm run doctor` 只检查运行前提，不发起 AI 请求，不打印账户标识或凭据。`npm start` 在前台运行，停止时按 **Ctrl+C**。

### macOS 双击启动

完成 Codex 安装和登录后，在项目目录双击 **启动知页.command**。首次启动会安装缺失的项目依赖、构建前端并打开浏览器；之后可以关闭启动终端，服务继续在后台运行。

双击 **停止知页.command** 关闭通过启动脚本启动的服务，已保存的学习资料保留。通过 `npm start` 启动的服务请在原终端按 Ctrl+C 停止。

如果从 ZIP 下载导致脚本没有执行权限，先运行：

```bash
chmod +x 启动知页.command 停止知页.command
./启动知页.command
```

### 自定义 Codex 路径

默认从 `PATH` 查找 `codex`。如安装在其他位置，可在同一个终端指定可执行文件，然后启动：

```bash
# 将占位路径替换为你自己的 codex 可执行文件路径
export PAPER_CODEX_BIN="/path/to/codex"
npm run doctor
npm start
```

无需创建 `.env` 文件；当前程序不自动加载 `.env`。在 WSL2 中需要在 WSL2 内单独安装和登录 Codex。

## 使用流程

1. 点击「导入论文」选择文件，或粘贴一段英文。内置的 Attention 入门材料为教学示例，不是正式论文。
2. 点击「翻译这一页」，完成后自动保存。选择「翻译全文」将逐页调用 Codex，跳过已有逐句译文；可随时停止。旧版整页译文会保留，点「升级为逐句对照」成功后才替换。
3. PDF 默认进入「版式对照」，可直接在原页文字或中文上点击／拖选；对应句子会双向高亮，另一侧自动定位。底部句对卡片显示完整内容，可逐句导航。点「讲解选句」交给 Codex，或点「记笔记」。
4. 需要更大文字时切换「段落精读」，也可以使用缩放菜单。版式内较长译文右下角的 `↗` 可展开到精读，不会丢弃全文。点右上角「学习助手」自由提问，或使用论文概览、术语解释、自测入口；上下文可选当前页或限量全文。同一文档保留独立对话，最近 8 条消息用于连续提问。
5. 需要外部资料时打开「联网」。普通提问默认不联网；翻译请求始终不联网。
6. 在「学习笔记」记录自己的理解，或将回答存为笔记。导出按钮生成包含笔记和对话的 `.md` 文件。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm ci` | 按锁文件安装项目依赖，包含构建与运行所需开发依赖 |
| `npm run doctor` | 检查 Node.js、操作系统、Codex 参数和登录是否可用 |
| `npm run build` | 准备本地 PDF 资源、进行 TypeScript 检查并生成前端产物 |
| `npm start` | 在 `127.0.0.1:4317` 前台运行已构建的应用 |
| `npm run dev` | 开发模式：Vite 使用 `4317`，后端使用 `4318` |
| `npm test` | 运行测试；使用模拟 CLI，不需要真实 Codex 登录，不消耗 AI 额度 |
| `codex login` | 登录或重新登录自己的 Codex 账户 |

更新项目后执行：

```bash
git pull --ff-only
npm ci
npm run build
```

然后重启服务并刷新页面。不要同时运行生产服务与开发服务，以免端口冲突。

## 数据、隐私与费用

- **本地资料**：原始文件、译文、笔记、页码和对话保存在浏览器 IndexedDB，服务器不建立文献数据库。请固定使用 `http://127.0.0.1:4317`；不同浏览器或地址的数据不互通。清理站点数据会删除资料，建议及时导出笔记。
- **AI 数据发送**：点击 AI 功能时，将选段、当前页或最多前 **60,000 字符**的全文及有限历史对话发送给 Codex。PDF 原始文件由浏览器本地解析，不整体上传给本项目后端。
- **账号与额度**：身份验证由每位使用者自行安装的 Codex CLI 管理。应用不读取或复制认证文件，不提供共享账号，不承诺免费 AI 服务。
- **运行方式**：服务仅监听本机回环地址，检查 Host、Origin 和请求令牌。当前版本面向个人本机使用，不应直接开放公网或作为多用户服务部署。
- **代码与运行数据分离**：公开仓库不包含个人 Codex 配置、凭据、会话、日志、论文、笔记或本机验证截图。详见 [隐私与数据说明](PRIVACY.md)。

## 当前限制

- 单文件最大 **30 MB**；PDF 最多 **300 页**。
- 扫描件可查看，但需要先用其他工具做 OCR 才能翻译；尚无 OCR 或图表图像问答。
- 原文画布保持 PDF 原貌；中文长度与英文不同，译文采用原区域内的自适应字号，不能保证每个换行和字形与原文相同。过长译文可在区域内滚动或点 `↗` 完整展开。
- 分栏和段落来自几何位置推断；复杂表格、彩色背景、重叠文字、旋转或竖排内容可能无法准确恢复。独立公式保留原图，行内公式及文字提取需对照原文核对。
- 句子对应依赖明确的原文 ID；返回漏句或重复 ID 时整页翻译会失败并保留旧数据。尚不支持把旧版整页译文自动猜配成句对。
- 每次 AI 请求最长 **3 分钟**，同时最多执行一个请求；全文问答不是无限上下文。
- 暂无云同步、完整文献库备份恢复或多人协同。
- AI 解释和搜索结果需要核对原始来源，不能代替阅读论文证据。
- 自动测试覆盖流式协议、进程取消、分栏顺序、跨行句子、翻译锚点完整性及输入上限。浏览器验收使用独立示例 PDF，覆盖导入、真实翻译、原位选句、反向定位及页面渲染。

## 常见问题

**提示没有安装或登录 Codex**：运行 `npm run doctor`，确认启动服务的终端能执行 `codex`。需要时重新运行 `codex login`，然后在页面的连接设置里重新检测。

**提示 CLI 参数不支持**：执行 `npm install -g @openai/codex@latest`，再运行 `npm run doctor`。本项目使用非交互 CLI 功能，旧版本可能缺少所需参数。

**页面无法打开或端口被占用**：确认 `npm run build` 成功并且服务仍在运行。macOS 后台启动失败时，可查看本机 `.runtime/server.log`；对外分享日志前自行删去私人内容。

**换浏览器后文献不见了**：这是不同浏览器的独立本地存储。请回到原浏览器和原地址，或使用导出的 Markdown 学习记录。

**导入后没有文字**：通常是扫描件或图像 PDF。先做 OCR，再重新导入。

**需要安装浏览器扩展吗？** 不需要。普通使用通过网页的文件选择器导入文档，与浏览器自动化扩展无关。

## 开发与贡献

前端使用 React、TypeScript、Vite 和 PDF.js；后端使用 Node.js、Express 和 Codex CLI。PDF 字体、字符映射和解码模块在构建时复制到本机静态目录。

提交前请运行 `npm test` 和 `npm run build`。不要提交 `.runtime`、`.env`、AI 登录目录、凭据、个人文献、日志或未经脱敏的截图。测试使用模拟 CLI，不应要求贡献者提供个人 AI 登录。

Codex 接入依据：[官方非交互模式说明](https://learn.chatgpt.com/docs/non-interactive-mode)。
